Two visual states, one rule
A dashed border and muted text mean inherited; a solid border means set here. The line under every field names the source folder, so nobody has to hover to find out who set their username.
Override and revert are both one click
The revert button carries the value it will restore — "Revert to inherited (22)" — so the consequence is legible before the click.
Agent forwarding earns its warning
Off by default, and the warning states the consequence rather than the mechanism, as the writing rules require.
