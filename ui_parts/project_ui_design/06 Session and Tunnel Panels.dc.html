Route is a column, not a tooltip
When a session goes through two bastions, that is the first thing you want to know when it gets slow. 148 ms next to "bastion → jump-eu" explains itself.
Exposed forwards are loud
A remote forward bound to 0.0.0.0 opens a path back into your machine. It gets a red row, a red address and a labelled badge — three signals, not one colour.
A bind failure says which port
"Port 3306 is already in use on this machine" and a retry button, rather than a red dot the user has to investigate.
