Where should the vault live?

One file holds everything. Back it up like you would any other file you cannot lose.

Acme Production
~/Dropbox/vaults/
acme-production.rvault
This folder syncs to Dropbox
It will work. Two things to know: editing from two machines at once will produce a conflicted copy, and Dropbox keeps historical versions of the encrypted file — including ones protected by a password you later change.
Shown once. You will not be asked again for this vault.

Choose a master password

Length beats symbols. There are no composition rules here because they reliably produce worse passwords.

canoe-thicket-marble-drift-9
Strong ≈ 72 bits
Centuries of guessing at a billion attempts a second. Argon2id makes each guess cost 256 MiB of memory.

Confirmation matches.
This password never leaves your machine and is never stored. It derives a key that unwraps the vault key. If you forget it, only the recovery key from step 4 will get you back in.

Add a key file

optional

A second factor: any file you choose becomes part of the key. Something you know plus something you have.

/media/usb-key/acme.keyfile
Not in the same folder as the vault, which is what you want.
This file is now required to open the vault. If you lose it, only your recovery key will work.

Your recovery key

Shown once, now. It is the only way back into this vault if you lose your password or your key file.

R7K2 M9XQ 4TVB P3ZW HD68 CN5L JS1F Y0GA
Type group 3 to confirm you have it somewhere safe.
4TV
One more character
There is no way to recover this vault without one of its keys
No escrow key, no support override, no vendor backdoor. If your password, your key file and this recovery key are all lost, the connections and credentials inside are gone permanently. Store this key offline — printed, in a safe, or in a different password manager.
