Screen designs for a connection manager that holds every credential you own

Built from docs/ui/design-system.md and docs/ui/information-architecture.md. The repository is in its design phase — there is no application code, so nothing here is a recreation. Every value below traces back to a rule written in the docs; where the docs left a token as …, I chose it and said why.

01

Assumptions

Dark is the shipped default
You left the theme question open. The docs say the default follows the OS and that four themes ship. I designed dark first and show light as a token override in Application settings.
Linux, GNOME-style header bar
A single client-side title bar, no menu bar. Window controls sit right. The same layout works on Windows; macOS moves the controls left.
1440 × 900 reference window
Large enough for three columns, small enough that the inspector has to earn its place. The narrow-window behaviour is noted per screen rather than drawn.
Sample estate from the docs
Acme Production: web-01, db-01, bastion-2, ctso-dc01, svc-deploy. Numbers are plausible, not measured.
02

Colour, and why

The token file specifies names, not values. The constraint that decided the palette: the accent cannot look like any session state. Connected is green, connecting amber, failed red — so the accent has to sit outside that range. A phosphor cyan does, and it belongs to terminals by heritage.

03

Five rules I held myself to

01
Nothing is colour-only. Every state carries a glyph and a word as well as a hue. A red tab also says prod.
02
The session is the content. Chrome totals 268 px of the 1440. The terminal gets the rest and can take all of it.
03
Inheritance is always traceable. Every inherited field names its source folder inline. No hover, no tooltip.
04
Failures name what, where, and what next. Every error screen is lifted verbatim from the failure taxonomy and given a primary action.
05
Dangerous actions look dangerous. Broadcast typing, plaintext export and a changed host key each get weight proportional to what they can cost you.

Open questions for you

?
Protocol icons. The spec requires SSH, RDP, VNC and SFTP to be distinguishable at 16 px. I drew placeholder glyphs in Lucide's language. Real ones need an icon designer, or the Lucide set dropped in.
?
The inspector's default. I have it closed by default and opened by F4 or a click on the connection name. Open-by-default costs 320 px of session width permanently.
?
Framebuffer sessions. RDP and VNC tabs are drawn as placeholders — a real screenshot of a remote desktop would be needed to judge the chrome around them.
