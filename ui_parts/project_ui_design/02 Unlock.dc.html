The failure message says nothing
"That did not unlock the vault" covers a wrong password, a wrong key file, or both. Telling someone the password was right but the key file was missing hands them half the answer.
Except when the file is broken
Once a slot has unwrapped, being specific leaks nothing to anyone who could not already open the vault — so that case names itself and points at the backups.
Only real slots are listed
A vault with one password slot shows one row. The hardware slot moves to the top when it exists, because touching a key beats typing a passphrase.
