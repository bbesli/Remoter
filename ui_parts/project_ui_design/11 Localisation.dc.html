What mirrors under RTL
Layout and directional icons. The sidebar moves right, tree indentation runs right-to-left, and the chevron, the SSH prompt glyph, the folder tab and the magnifier all flip.
Object icons do not. The monitor, the key, the record dot and the close cross look the same in every direction — mirroring them just makes them look wrong.
The terminal never mirrors. It is a fixed grid of remote output. It stays LTR inside an RTL window, and so do hostnames, ports, IPs and timestamps.
What Turkish exposed
1
"Veritabanı katmanı" is 20 characters against "DB tier"'s 7. Tree rows must truncate with an ellipsis and never wrap; the sidebar is resizable for exactly this reason.
2
"kasa 12:04 içinde kilitlenecek" puts the number in the middle of the sentence. No string may be assembled from fragments; each is one translatable unit with a placeholder.
3
Decimal comma: 2,1 MB in Turkish, 2.1 MB in English. Durations abbreviate differently too — 1g 6s, not 1d 6h.
4
Turkish lowercases I to ı. Search folds diacritics and uses locale-aware casing, so sunucu finds Sunucu and munchen finds München.
