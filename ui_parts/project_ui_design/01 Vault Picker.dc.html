Why the slot badges
Each vault shows which unlock methods it has before you pick it, so you know whether to reach for your security key. The unlock screen then leads with the fastest one.
Unreachable vaults stay visible
The vault on the unmounted USB key is not hidden — it is shown, disabled, with the reason. Hiding it would look like data loss.
