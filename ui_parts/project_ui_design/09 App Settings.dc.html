Plugins

Plugins run in a WebAssembly sandbox and can only do what you grant. Capabilities are listed before you install, not buried in a manifest.

k8
Kubernetes execv0.4.2 · community · 1.1 MB wasm
network: *.k8s.acme read: ~/.kube/config no vault access
ssm
AWS Session Manager transportv0.2.0 · community · 2.8 MB wasm
network: any host read: ~/.aws
Requests unrestricted network access. Enable only if you trust the publisher.
Themes are plain data and need no sandbox, so they install separately.
Themes are shown, not named
Each swatch is a miniature of the real window, so "high contrast dark" is a picture rather than a promise.
Conflicts are surfaced, not silent
Ctrl+Tab collides with the GNOME switcher; the row says so and says who wins, instead of the shortcut mysteriously not working.
Capabilities before install
"No vault access" is stated as a positive fact, because for a plugin in a credential manager that is the most reassuring line on the card.
