Marks come from a pattern list you can edit. They are hints for finding things, not a security control.
Three events get a coloured row
A changed host key, broadcast typing, and a plaintext export. These are the entries someone reviewing an incident is looking for, so they are findable while scrolling fast.
The recording is text
asciicast v2 means the search box searches the session, not a video. Matches are timestamps you can jump to, which no screen recording can offer.
Graphical recordings need a different player
RDP and VNC recordings have no text to search. That player — frame scrubbing, dirty-rectangle heatmap — is not drawn here. Say if you want it.
